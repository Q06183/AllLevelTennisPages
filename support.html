Common Questions

Where is my data stored?

Your training records, notes, student profiles, lesson plans, and schedules are stored locally on your device. AllLevelTennis does not run a backend server for this app.

How do I move data to a new device?

Use the app's backup export feature to create a JSON backup file, then use the restore feature on the new device to import that file.

Can I use the app without an account?

Yes. The app is designed to work without registration. Student mode and coach mode are available through the app's mode switch.

How do I recover a deleted student?

Coach mode includes a recycle bin for deleted student profiles. Deleted students can be restored from the recycle bin before permanent deletion.

Does the app track location?

No. If you enter a court or venue name in a lesson plan, that text is stored as part of your local app data. The app does not request background or precise location tracking.
